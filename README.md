# Fruit Catching Game

A simple and fun Fruit Catching game built with JavaScript. The objective is to catch falling fruits and score as many points as possible.

## Features

- Colorful fruit graphics
- Increasing difficulty as you play
- Score tracking
- Responsive and interactive gameplay

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/mujtabaahmad212/fruit-catching.git
    cd fruit-catching
    ```

2. Open the `index.html` file in your web browser to play the game.

## Tech Stack

- JavaScript
- HTML5
- CSS3

## Usage

- Use your keyboard (usually arrow keys) or mouse to control the basket and catch the falling fruits.
- Try to catch as many fruits as you can to increase your score.
